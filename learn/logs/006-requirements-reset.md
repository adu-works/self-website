### 知识点 1：Path 代表文件路径

```python
from pathlib import Path
p = Path('docs/05-collaboration/interaction-ledger.md')
s = p.read_text()
p.write_text(s)
```

`Path` 表示一个文件位置；`read_text()` 读取文字，`write_text()` 写入文字。写入会覆盖该文件，因此实际修改前先确定范围，重要旧稿先保存。这个片段说明本轮用到的读写方式，不建议不经检查批量替换所有代码。
