## 语言课堂（本次用到的 TS/Python 知识点）

本轮用的是 JavaScript 模块，没有新增 TypeScript/Python 业务代码。

```js
const {createProjectScene}=await import('./project-scene.mjs');
```

`import()` 返回 Promise；`await` 等待模块可用，花括号取出模块的导出函数。把它放在作品详情初始化时，首页就不会下载 Three.js。异步等待期间可能已经离开页面，所以后面再次检查 `disposed`，避免把已过期的场景装回 DOM。

```js
return a+(b-a)*t;
```

这是插值：t 从 0 到 1 时，由起点 a 走向终点 b。三维旋转和位置都由当前滚动进度直接算出，不靠累计上一帧位移，所以回滚不会产生漂移。GPU 对象不能只删除 HTML 就算释放；几何、材质、贴图和渲染器分别 dispose。

## 你自己动手（练习）

把 `.23` 镜头的 `ry` 改小，观察拆解朝向。再改回，执行测试。不要直接改上一帧旋转累加；比较上下滚动经过同一位置时是否得到同样画面。

## 扩展思考

参考动效时，先写清“哪一个对象，在什么页面，随着什么操作，发生什么视觉变化，说明什么价值”。仅写“参考高级感”容易把模型拆解做成普通内容轮播。新项目应使用自己的功能和界面，不一律套阅读示例。
