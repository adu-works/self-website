## 这次做了什么

首页显示本人明确提供的姓名，链接到七平台社媒页。将完整项目文档和原型归档到 adu-works 的私有 GitHub 仓库。

## 实现顺序（先写什么、再写什么，为什么）

1. 核实姓名授权、账号信息与仓库归属，避免根据姓名猜链接。
2. 制作独立目录并复用已有导航，未确认 URL 保留为空。
3. 验证页面、发布原型，再同步项目仓库；保留 Sites 独立历史。

## 关键决策

| 决策点 | 选择 | 为什么 | 落选方案 & 为什么 |
|---|---|---|---|
| 空地址 | 不可点击占位 | 不误导访客 | 平台首页不是个人账号 |
| 仓库权限 | 私有 | 包含尚未确认的项目材料 | 未经要求不公开全部文档 |
| 社媒维护 | 独立数据文件 | 用户可自行替换 URL | 分散写进每个模板难维护 |

## 语言课堂（本次用到的 TS/Python 知识点）

页面使用 JavaScript。`url:null` 表示链接未知；模板按 `a.url` 判断是否生成链接。它不同于 `href="#"`，后者仍可点击却没有正确目的地。Git 归档脚本使用 Python pathlib 遍历文件并排除嵌套 Git 元数据。
