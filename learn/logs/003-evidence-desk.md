# 日志 003：原型场面（证据桌）

> 日期：2026-09-16 ｜ 对应路线图：G2 原型 ｜ 涉及代码：`docs/02-prototype/v0.1/index.html`、`assets/os.css`、`assets/os.js`、`home.html`

## 这次做了什么

把工作台外壳从「灰米色系统桌面」改成一张**会跟着指针动的证据桌**：深色、金光、颗粒、第一人称问候、可点的纸条。
它在产品里的角色仍是评审用原型，不是上线视觉定稿；窗口里的 14 个页面和问答/管理端状态机没有改逻辑。

## 实现顺序（先写什么、再写什么，为什么）

1. **先改 `index.html` 的场面结构**（问候、纸条、颗粒、光晕），因为没有 DOM 节点，CSS/JS 无处附着。
2. **然后写 `os.css` 的气氛层**，因为光标、视差、开机字号都是纯表现，不依赖窗口管理逻辑。
3. **再补 `os.js` 的指针追踪、纸条开窗、程序坞磁吸**，因为它们要读已有的 `openWindow`。
4. **最后改 `home.html` 开场问候**，保证单独打开首页时也是同一个人，而不是两套人格。

## 关键决策

| 决策点 | 选择 | 为什么 | 落选方案 & 为什么 |

## 语言课堂（本次用到的 HTML/CSS/JS 知识点）

### 知识点 1：用 CSS 变量把指针位置传给样式

```js
desktop.style.setProperty('--mx', x.toFixed(3));
desktop.style.setProperty('--my', y.toFixed(3));
```

```css
transform: translate3d(
  calc((var(--mx) - .5) * 28px * var(--d)),
  calc((var(--my) - .5) * 18px * var(--d)),
  0
) rotate(var(--r));
```

`--mx` / `--my` 是 0 到 1 的比例。纸条不跟手 1:1，只按深度 `--d` 挪一点点，看起来像桌上的纸，而不是粘在光标上。
常见错误：用 `left`/`top` 跟手会触发布局；这里只动 `transform`。

### 知识点 2：错峰出现靠 `--i`，不必给每个字写 animation-delay

```html
<span style="--i:0">你</span><span style="--i:1">好</span><span style="--i:2">。</span>
```

```css
.boot-hi span {
  animation-delay: calc(80ms + var(--i) * 100ms);
}
```

`--i` 是自定义属性。`calc()` 里可以拿它做延迟。以后加字，不用改 CSS。

## 扩展思考

真做产品时，桌面物件应来自真实项目/文章，不能再是示例纸条。自定义光标与 iframe 窗口是结构性冲突，实现阶段若仍用窗口，应放弃自定义光标或不用 iframe。
