## 这次做了什么

## 实现顺序（先写什么、再写什么，为什么）

1. 检查当前 Git 状态与 worktree 依赖，避免删除旧目录时破坏新版。
2. 保存 Sites Git 元数据到项目外，迁移当前原型并核对运行文件哈希。
3. 编写方案和24项任务；修复文档入口与链接，执行原型回归后提交推送。

## 关键决策

## 语言课堂（本次用到的 TS/Python 知识点）

本轮没有正式 TS 功能实现。Python 的 pathlib 用于路径处理，hashlib.sha256 比较迁移前后文件；subprocess.run(check=True) 遇到失败停止。文件名改变不等于内容改变，哈希用于核实后者。

`git config user.name` 是提交署名；`gh auth switch` 切换 GitHub 登录凭据。二者不是同一个概念。
