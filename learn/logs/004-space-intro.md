# 日志 004：首页 3D 太空入口

> 日期：2026-09-16 ｜ 对应路线图：G2 原型 ｜ 涉及代码：`docs/02-prototype/v0.1/assets/intro.js`、`intro.css`、`index.html`、`os.js`

## 这次做了什么

在证据桌前面加了一段可玩的 3D 首页：纸飞机在星空里飞，穿过写着「工作台」的金色光环就落到桌子上。
它在产品里只承担**进门**，不代替项目、问答和管理端。

## 实现顺序（先写什么、再写什么，为什么）

1. **先改阶段切分**（`data-phase="intro" | desk"` 和 `proto:enter-desk`），因为 3D 和桌子必须互斥，否则窗口快捷键会在飞行时被触发。
2. **再写场景与飞行**（Three.js CDN），因为没有场面就无法评审「像不像 Bruno 那种能玩」。
3. **最后补失败路径**（跳过、减少动效、引擎未加载），因为进门失败不能挡住主路径。

## 语言课堂（本次用到的 JS 知识点）

### 知识点 1：四元数把「机头朝向」变成位移

```js
var forward = new THREE.Vector3(0, 0, -1).applyQuaternion(ship.quaternion);
ship.position.addScaledVector(forward, speed * dt);
```

Three.js 里物体默认朝向是 −Z。`quaternion` 是旋转的数学表示。把 (0,0,−1) 用飞机当前旋转变一下，就得到机头方向，再沿这个方向移动。不要用 `rotation.y` 自己推三角函数，转着转着会万向节锁死。

### 知识点 2：脚本比监听先跑时，用旗标补上丢失的事件

`intro.js` 若在减少动效时立刻 `dispatchEvent`，`os.js` 可能还没 `addEventListener`，事件会丢。所以先设 `window.__protoIntroDone = true`，桌面脚本启动时再读一次旗标。
