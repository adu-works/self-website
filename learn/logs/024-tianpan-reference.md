# 日志 024：核对 TianPan.co 与公开源码

> 日期：2026-09-20 ｜ 对应路线图：G2/G3 参考调研 ｜ 涉及代码：无产品代码修改

## 这次做了什么

按用户新增参考，阅读 TianPan.co 首页、课程、文章与会员介绍，通过 GitHub API 核对公开仓库，并查到作者的网站架构说明。将适合本项目的设计建议记入模块 01，不另建研究报告。

## 实现顺序（先写什么、再写什么，为什么）

1. **先核对页面结构**，识别个人定位、内容与付费入口如何关联。
2. **然后查仓库及作者说明**，区分旧站、内容库和未找到的整站源码。
3. **最后记录适用建议**，避免参考一个网站就推翻既定商业方式。

| 决策点 | 选择 | 为什么 | 落选方案 & 为什么 |

## 测试

核对公开页面、仓库根目录及作者架构文章；未测试订阅付款、登录或私有后台。仅文档变化，检查 Git diff，不重复执行原型测试。
