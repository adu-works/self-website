## 关键决策

| 决策点 | 选择 | 为什么 | 落选方案 & 为什么 |
|---|---|---|---|
| 语言 | TypeScript 全栈 | 共享契约和工具链，降低个人维护成本 | Python 后端目前没有独有依赖，却增加运行环境 |
| 后端结构 | Route Handlers + 独立业务服务 | 保留权限、事务、测试边界 | 页面直接操作数据库会混淆职责 |
| 教学 | 按实际 TS/Node.js/SQL 讲解 | 仍可从零学习完整后端工程 | 为讲 Python 强行新增服务不符合项目优先级 |
