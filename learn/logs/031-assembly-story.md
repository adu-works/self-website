3. 检查组装和反向恢复，手机改为静态可读布局，并同步范围文档。

## 语言课堂（本次用到的 TS/Python 知识点）

仍是 JavaScript 原型。`Math.max(0, Math.min(1, value))` 把滚动进度限制在 0 到 1；`1-(1-arrival)**3` 让模块接近目标时减速。位置完全由进度决定，没有累加偏移，因此反向滚动可恢复。负数乘零可能得到 `-0`，几何测试应检查数值是否为零，而不要求序列化或严格对象比较中符号相同。

## 测试

新增进度边界和可逆/归位两项测试；首次测试因 -0 与 0 的对象严格比较失败，调整为符合几何目标的数值断言后，14 项测试全部通过。脚本语法检查通过。浏览器检查桌面拆分与组装状态；移动和跳过检查结果同步到原型验证记录。
