## 原材料中需要澄清的事项

- 文件名为 p5，正文标题为 P3，又称第四个招牌作品：本站统一称“个人平台”，不推断组合项目编号。
- F2 标为 Q4，但早期要求项目占位、Q3 嵌入问答：提议拆为基础项目展示与后续深度证据/问答。
- “五个项目四件套”未定义具体项目和四件套组成：等待用户提供，不凭空补经历。
- F8 提到订单与预约，不代表第三方一定开放所需 API；后续必须核验权限、成本、接口与替代路径。
- “一句话发文”与“写操作必须确认”同时存在：解释为一句话生成发布提案，再经确认发布。
- 初期手动发布与最终 Agent 运营并存：前者是过渡能力，未完成时不宣传为已实现 Agent 运营。

本仓库 PRD 中的首版拆分、验收门槛、隐私建议均为待评审提案，不是用户已经批准的需求。
