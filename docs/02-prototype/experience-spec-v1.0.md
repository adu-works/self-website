## 1. 设计判断

采用火星探索作为个人站入口。它有两个明确的回报：愿意探索的人获得船票，带着问题进入 AI；希望快速了解站长的人砸炉或直接进入主站。两条路线始终互通。

网站暂用设计名称“远行手记 / FIELDNOTES”。这是本次创作的名称，不是对站长身份或真实品牌的推断。主站围绕项目、文章和个人介绍展开，阅读不依赖游戏或模型配置。

## 2. 首次旅程

| 顺序 | 场面与动作 | 结果 | 返回与跳过 |
|---|---|---|---|
| 1 | 火星上，近景角色与熔炉，远处小坡 | 可点击地面、WASD/方向键移动；手机方向按钮 | 顶部直接浏览、问问 AI 始终可见 |
| 2A | 熔炉旁打造铲子，显示打造过程 | 铁料换为铲子；角色持铲 | 不设计额外采矿、背包管理或失败惩罚 |
| 3A | 前往坡后，执行挖掘 | 宝箱出现，进入配置 | 已获铲子与挖宝进度在本次页面会话保留 |
| 4A | 选择模型厂商、模型和 Key | 验证通过后显示星际船票 | 无效、限流、网络失败都允许重试或取消 |
| 5A | 登船、升空、地球大气层转场 | AI Chat 出现 | 可以跳过；减少动效时快速抵达 |
| 2B | 搬起并砸掉熔炉、火花散开 | 直接进入主站 | 不需要模型配置；不破坏真实内容 |
| 6 | 在 Chat 中回收飞船 | 回到主站，当前对话保留 | 再次打开 AI 不重做探索 |

原型的移动与动画是功能性演示，不包含碰撞物理、角色 IK、复杂地形寻路或电影级角色资产。坡后交互采用引导移动与镜头切换，键盘/按钮路径能够完成同样任务。

## 3. 画面与动效规范

- **火星**：陶土红地表、酒红天空、暖色炉火，远处蓝色地球。生成的全景气氛素材与实时 3D 可交互物件结合。角色采用简化宇航服与头部轮廓，不声称是站长肖像。
- **飞行**：从暖色火星转到深空与蓝色大气层；地球图片承担主要视觉，飞行可跳过。
- **主站**：深蓝黑 `#11191C`，纸白 `#EFE9DE`，强调橙 `#EC8151`，引用蓝 `#9ED8E8`。正文稳定、宽度受控，项目图与标题形成层级。
- **字体**：Space Grotesk 与 Noto Sans SC；字体加载失败退回系统无衬线。大标题按视口缩放，正文 16px 起，次要元信息 12px，主要控制不低于 14px 的桌面设计基准。
- **布局**：顶部固定导航；场景指引放左下；物品状态右下；手机重新排列，使用单列阅读与可触控操作。
- **动作**：打造约 1.8 秒；引导行走后挖掘；砸炉约 2.3 秒；飞行约 5.4 秒；回收过渡约 0.5 秒。均为原型值，审美评审可调整。
- **减少动效**：遵循系统偏好，也提供手动开关；不影响按钮任务路径。火星与正文保持可读，不以闪烁作为必要提示。
- **可访问性**：语义化按钮、原生模态框焦点约束、明确表单标签、错误反馈、键盘移动替代。正式无障碍验收不由一次原型检查代替。

## 5. 访客自带模型配置

字段为厂商、API Key、模型，以及需要时的接口地址。厂商选项在原型中仅作交互示意，不承诺正式版已支持这些服务。

原型 Key 输入固定为假值并只读；用户不需要也不应提供真实 Key。模型名称和厂商可调整，演示选择器可切换有效、无效、模型不可用、余额不足/限流、网络失败。整个原型不会把配置发送给模型服务。

正式产品设计要求：默认本次会话使用、清除配置可见、秘密不进入网址/票面/分享/日志；用户清楚知道服务目的地、发送的问题及公开材料、费用归属。具体请求通路、厂商兼容、自定义地址约束、凭据生命周期必须在 G3 设计并验证，不能提前承诺浏览器直连或服务器代理。

验证与飞行动画分离：验证失败不签发船票；动画失败不应使已验证配置失效。取消配置回到原上下文。清除后普通阅读继续可用。

## 6. AI Chat

- 可询问公开博客、项目和“关于我”的资料，正文页进入时显示当前范围。
- 每条回答明确为模拟；采用预设匹配，不能当作真实检索质量证明。
- 回答提供可点击文章/项目来源；原文可返回对话。
- 未提供个人资料时说明不知道，不利用文件夹名或故事角色编造站长身份。
- 演示空白、等待、停止、回答、资料不足、服务失败与限流。失败保留问题；重复发送不产生并发重复任务。
- 主站打开 AI：未配置先配置，配置可用继续 Chat。回收只收起界面，不清除会话；显式新对话和清除配置是不同动作。
- 访客问答不能访问私有草稿或站长工具。真实隔离必须在工程实现验证，原型不是鉴权系统。

## 7. 站长 Agent 演示

独立工作台入口，不把管理动作放进访客聊天。提供更新项目与新建文章草稿两类示例。提交材料后先呈现前后差异、目标和版本；支持取消、确认、执行结果、版本记录和恢复差异。

演示结果包含：全成功、保存失败、发布成功但来源更新失败、内容版本冲突、结果待核实；失败不自动重发，结果未知先核实。模拟登录过期阻止现有提案执行。恢复旧版须再次检查具体差异。

站长界面只是流程原型，不具有真实认证、数据库、发布、索引或版本控制能力。数据刷新即重置。M1 的正式后端与权限机制仍属 G3/G4。

## 9. 交付文件与维护方式

- 原型独立保存在 `v1.0/`，旧 `v0.1/` 不覆盖。
- `v1.0/dist/` 为静态交互原型；`app.js` 管理界面状态与示例内容，`scene.js` 管理场景，`style.css` 管理外观。
- 生成图像用于气氛和项目演示图；来源与依赖许可证见原型 README。
- Sites 以所有者私有方式交付原型，未更改为公开站点。该链接发布的是原型，不是正式个人网站上线。
- 本次完成后，用户评审视觉、动作、信息和流程；通过后再冻结工程范围、产出实现方案与规划。
