## 不做扩大解释

- 上述是模拟流程，不是实际厂商连接、检索准确性、认证隔离、发布或数据库恢复测试。
- 未逐一人工走完所有异常组合；模型不可用、网络失败、限流、管理保存失败/冲突/未知/登录过期等已提供演示入口，但不声称全部进行了独立回归。
- 未完成 200% 文字放大、屏幕阅读器、所有键盘焦点顺序、低端真机性能与跨浏览器完整审计。
- 场景角色、升空与回收为简化原型动作；没有复杂物理和正式角色资产。截图仅当场观察，未交付截图文件。
- WebGL 失败时的普通按钮替代存在于代码；本次没有主动破坏 WebGL 环境做故障注入。
