## 对设计提案的具体调整

以下是 Agent 的建议，均未成为用户批准的需求。

1. **A 创作室的记忆点应与内容有关。** 若采用物件，用它打开对应内容，如笔记对应文章、作品物件对应项目；具体物件由真实兴趣与素材决定。保留清晰文字入口。
2. **B 桌面要评审一条完整浏览链。** 从默认欢迎内容进入文件夹，再打开正文、切换窗口和返回；仅展示几个可拖动卡片不足以验证这个方向。检查首次窗口是否完整可见，关闭后焦点是否可找回。
3. **C 展馆可以是导航空间。** 不限定为看完动画再进入普通首页；允许点击场景物件直接进入内容。同时提供普通导航、作品独立地址与跳过路径。
4. **阅读与 AI 的连续性要单独验证。** 文章/项目中打开问答、打开引用、关闭问答后回到原位置。该链路是本站功能推导，不能声称参考站已展示了这些 AI 能力。
5. **动效通过可点击的样例评审。** 给打开、关闭、定位或参数变化各一个明确结果；减少动效时仍完成同一任务。不要用“高级、丝滑”替代可检查的行为。

## 原型评审时可复用的体验路线

- 首次进入：能知道是谁、能看什么；探索和直接浏览都能找到。
- 内容链：入口 → 列表 → 详情 → 返回，地址与当前位置可理解。
- 交互反馈：对象响应、加载反馈、关闭/返回、键盘操作；手机另测。
- 本站特有：内容 → AI 问答 → 引用 → 返回正文；管理提案 → 差异 → 确认/取消/失败，均使用标注模拟。

本次只深化研究，没有制作或批准新原型，没有修改 PRD 首版边界。当前选择入口仍为[设计提案](design-brief.md)，阶段记录见[status](../00-project/status.md)。
