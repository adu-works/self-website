# 远行手记 · 完整体验方案 v1.1

> 2026-09-16 · 根据用户对 v1.0 的明确反馈重做，待验收。火星主题不变，本版替代 v1.0 的场景、主站和聊天设计。真实后台仍未开始。

## 1. 核心判断与参考

个人站的体验分成三种节奏：火星上亲手探索；落地后安静对话；主站像一张刚刚展开的归航桌面。三者共享同一组项目、文章和个人信息，普通阅读不依赖游戏或模型配置。

本次应用 redesign-existing-projects 与 frontend-design 技能。重新操作 Shar 的 Work 窗口、Alana 的 Finder Projects，并查看 Notes 与消息窗口的组织方式；Greg 站本次返回 Application Error，没有把失败访问记成成功研究。完整历史研究见 reference-interactions.md。

- [Shar](https://www.sharyap.com/)：借鉴内容以可打开物件组织、轻盈背景和窗口层级；不复制其个人资料或窗口装饰。
- [Alana](https://www.alanagoyal.com/finder)：借鉴稳定的内容入口、清楚的阅读容器；不用完整仿操作系统增加学习成本。
- [Bruno](https://bruno-simon.com/)：沿用先前研究中“通过移动与动作发现内容”的原则。本轮重点修正动作和地形脱节，未声称达到其场景制作水准。

主站不再沿用 v1.0 的大标题、双项目卡片和文章列表作为首屏。主页把一个项目变成可打开的火星明信片、文章集合变成可打开的手记、个人介绍变成便笺、AI 入口变成船票。它们都是功能入口，不是不可点击装饰。

## 2. 火星场景与操作

| 阶段 | 用户动作 | 可见反馈 | 进入下一步条件 |
|---|---|---|---|
| 移动 | 点击地面、WASD/方向键或方向按钮 | 骨骼步行、转身、相机跟随 | 角色实际走近目标 |
| 熔炉 | 打开炉门 | 炉门绕铰链转开，炉火可见 | 门已开 |
| 锻造 | 独立点击三次“锻打一锤” | 每次锻打动作与火花，计数 0→3 | 三次动作各自结束 |
| 取工具 | 点击“拿起铲子” | 角色持铲、背包更新 | 已完成锻造 |
| 越坡 | 步行越过山坡 | 足下高度跟随连续地形，上坡减速并前倾 | 抵达坡后挖掘点 |
| 挖掘 | 独立点击五次“铲一下” | 挥铲、扬尘、土坑扩大；第三铲起露出箱体 | 五次动作各自结束 |
| 开箱 | 点击“打开宝箱” | 箱盖转开，再出现模型配置 | 已完成挖掘 |
| 配置 | 选择厂商、模型，验证示例 Key | 成功化作星际船票；失败说明原因 | 模拟验证通过 |
| 收票 | 点击“收好船票，去飞船” | 回到可移动场景 | 用户决定出发 |
| 开舱 | 走到飞船旁，点击“打开舱门” | 舱门转开、可见舷梯 | 用户靠近飞船 |
| 登船 | 点击“登上飞船” | 角色沿登船方向移动，进入舱内 | 登船动作结束 |
| 发射 | 点击“点火，前往地球” | 飞船升空、地球大气层转场 | 转场结束或选择跳过 |
| 另一条路 | 在熔炉旁“搬起熔炉”，再“砸下熔炉” | 搬起、落下、火花飞散 | 进入主站，无需模型 |

没有 E 自动推进，也没有点击一次完成整段打造/挖宝的动作。辅助“走向坡后”“走向飞船”只设移动目标，角色依然沿地形行走；不会自动挖掘、开门或配置。动作过程中按钮暂时禁用，避免连续点击跳过计数。

地形网格与角色使用同一高度函数。山坡有真实高差；熔炉、飞船有简化碰撞边界，地图有移动范围。场景不是物理沙盒：碎石目前不逐颗碰撞，不含双脚 IK、任意地形导航和真实破坏物理。辅助行走遇到障碍可停下，用户可改方向绕行。

## 3. 视觉与资源

- 火星：生成砂砾材质、连续高差、远山、材质凹凸、光照阴影和石块。远景天空使用生成气氛图，非 NASA 地形复原，也非真实火星摄影。
- 角色：Quaternius CC0 人形模型及已有骨骼动画，不是站长肖像。加载时先应用中立姿态，再测量包围盒，避免导出初始姿态造成尺寸错误。
- 开炉、箱盖、舱门：实时几何绕铰链运动。锻打和挖掘是轻量动作演示，不是定制电影级动画；这一限制不以“真实物理”包装。
- 主站：雾灰白底 `#EDF0EE`、石墨文字 `#293539`、深青手记与少量钴蓝。中文衬线用于阅读标题，正文保留清晰无衬线。物件有轻微旋转与悬停抬升，打开后进入稳定阅读页。
- Chat：近白底、安静的灰绿侧栏；消息自然排布，不给每一条 AI 回答套卡片。正文 16px；移动端 15px；次要票据与装饰信息可更小。
- 手机：桌面物件纵向编排、文章单列；Chat 顶部展开会话/配置，底部保留回收与新对话。没有横向滚动依赖。
- 减少动效：保留步骤与独立按钮，缩短动作和转场，不删掉操作本身。

资源来源与授权见 v1.1/ASSET-SOURCES.md。第三方库许可单独保留。

|---|---|---|
| 归航桌面 | 明信片、手记、概念卡、个人便笺、船票、导航 | 打开对应项目、文章集合、关于、AI；返回火星 |

## 5. Chat 与引用协议

Chat 打开时直接呈现对话空间。桌面侧栏占约 248px，余下宽度为会话区；消息区占剩余高度并独立滚动，输入区保持在底部。空态提示问题，开始对话后让位给消息。

引用是答案中的编号链接，并附可读来源名称。文章/项目引用地址包含目标段落，例如 `#/article/sources/section-1`。打开后滚动定位、高亮该段，并把焦点放到该段，提供“返回对话”。返回时保留消息；新对话会把旧对话放入本次访问历史。刷新会重置，本版没有持久化聊天。

回答依据不足时明确说明；未知个人经历不猜测。服务失败与限流保留输入、允许重试，停止生成不伪造完整答案。切换超出当前范围的问题先说明范围变化。真实检索、流式输出和答案质量评估仍待实现阶段。

模型配置沿用厂商、模型、Key、自定义接口的产品要求。原型 Key 是只读假值，禁用真实凭据输入，不发送模型请求。有效、Key 无效、模型不可用、限流与网络失败均可模拟。正式凭据处理与费用说明须在工程方案中确定；不能从本原型推断浏览器直连已被批准。

## 6. 站长 Agent 边界

首版仍包含站长内容管理 Agent，和访客问答权限分开。原型保留：项目更新或文章草稿→目标与前后差异→取消或确认→分别展示保存、发布、来源更新结果→版本记录及恢复预览。包含失效提案、失败、部分成功、未知结果与模拟登录过期。

所有管理操作仅改变内存。发送一句话不自动发布；恢复也是具体差异的再次确认。访客问答没有管理员工具。本轮是视觉和交互修改，没有新增真实登录、索引、写入或发布后端。

## v1.1.1 修订 · 放下与快捷键

用户要求搬起后也能放下，并增加快捷键。搬起时暂存原阶段；R 将熔炉平稳放回原位置，恢复碰撞和原阶段，保留炉门与锻打进度。X 才执行砸毁路线，E 在搬起状态没有默认动作，以免误砸。F 搬起，E 执行当前步骤（每一锤、每一铲仍需独立按下），G 辅助移动。按钮同步展示按键，鼠标和触控仍可用。

禁用长按自动重复；动画忙碌、弹窗、表单输入、输入法组合以及 Ctrl/Command/Alt/Shift 组合键不触发。此修订替代此前“没有 E”的表述：不接受的是 E 自动完成整段故事，当前允许 E 逐步执行单次动作。

## v1.1.2 修订 · 握持、负重与完整归航

来源：用户指出铲子漂浮、搬炉后跪地不能走、缺少火箭与大气层镜头，并要求落地开舱、伸懒腰、顺着目光进入页面。用户随后明确：**最终仍打开完整 Chat，随后可进入主站**。这是 G2 内的修改授权，不是整版验收。

- 铲子挂接右手掌的骨骼插槽，步行和铲土都随手臂运动；不再挂在角色根节点旁边。
- 搬炉使用站立/步行下肢动画与独立的双臂支撑姿态。负重速度降低，仍支持方向键、WASD、点地及触控移动。炉体跟随角色位置和朝向。
- R 在当前朝向前方有空间时平稳放下，恢复当前位置碰撞、炉门与锻打进度；空间不足提示换位置。X 仍为砸毁。**此项替代 v1.1.1 的“放回原位置、禁止负重移动”临时处理。**
- 归航由同一条约 27 秒场景时间线驱动：发射 3 秒 → 地球轨道 4 秒 → 大气层 4 秒 → 减速着陆 4 秒 → 开舱 2 秒 → 出舱 3 秒 → 伸展 3 秒 → 视线转场 4 秒。低帧率可能延长实际观看时长。
- 火箭在飞行镜头中持续可见；大气层用天空颜色、雾、云层和热辉表现。着陆后有实体舱口，角色出舱前收起工具，伸展后转头，镜头靠近眼睛并转向前方，Chat 渐显。
- “跳过飞行”直接进入 Chat；Chat 侧栏增加“重看归航 · 场景演绎”，用于重看动画。回收飞船仍进入主站，保留本次消息。减少动效保留事件顺序、缩短演绎；无须完成飞行才能阅读主站。

这里是可交互的程序化演绎，不声称摄影级人物、真实航天动力学或完整足部/手指物理。生产级资产与性能预算留待 G3。

## v1.1.3 修订 · 动作节奏与页面关系

用户反馈动作仍僵硬，要求出舱时镜头转到角色后方以接上眼睛视线，并要求核实所有返回。新增[页面关系与返回核查](navigation-audit-v1.1.3.md)，统一真实上一页、固定入口与弹窗层级；直接打开无历史的页面采用明确后备入口。保留列表筛选、浏览位置、Chat 草稿与工作台提案/结果。

每铲约 1.85 秒，按蓄力、入土、撬起、提起、收势分段；双臂配合工具，扬尘与入土节点对齐。伸展改约 4.2 秒，加入缓慢抬臂、短暂停留、躯干舒展和回落。归航因此约 28.2 秒场景时间。出舱镜头由前侧绕过身体侧面、到肩后，伸展期间继续小幅转向，随后推进至眼睛后方朝前看；不再从人物正面直穿脸部。关键镜头接缝和动作回到中立姿态均有测试。

检查发现有些模型关节没有动画轨道，增量旋转会累积；改成每帧从保存的基准姿态施加偏移，新增重复采样检查。仍是程序化演绎，不承诺动作捕捉级或物理仿真效果。

时间修正：v1.1.3 将演绎时间与真实经过时间对齐，移动积分仍保留步长限制，避免低帧率时动作还未收势，UI 却先完成。替代 v1.1.2 低帧率延长整段时长的临时行为。

## v1.1.4：视线匹配剪辑（2026-09-16）

来源：用户要求顺着目光、不要穿过头部，并最后修订不自然的伸懒腰。

出舱环绕保留。伸展用 4.2 秒完成站稳、抬臂、短暂停留、缓慢落臂；躯干仅轻微伸展，不摆动。腕部终点先解算成骨骼姿态，再对关节做球面旋转插值，避免腕部直线经过肩关节导致肘部折转。

最后 4 秒：前 45% 摄影机停留在肩后，人物望向远处，镜头朝相同目标摇转；随后直接切到面部前方的主观机位，维持目标方向，最后渐显完整 Chat。两个机位之间不做位置插值，切换后不绘制人物自身，防止近裁剪面截入头部。参考 [Columbia 电影术语：Eye-Line Match](https://filmglossary.ccnmtl.columbia.edu/term/eye-line-match/)。此前 v1.1.3 的环绕只能保证出舱段安全，不能保证最终推进段安全，本次补齐该约束。

## v1.1.5：从桌面物件到内容内页（2026-09-17）

来源：用户指出首页卡片打开后近似简单 Markdown 排版，要求内外一致、高端。

- 项目：大幅衬线标题与不对称摘要；火星项目用现有场景宽幅图，索引项目用主题纸卡构图。作品元信息、章节侧栏、路径示意、设计取舍双栏与下一项目组成案例阅读节奏。
- 文章：三篇独立题签；草绿探索箭头、蓝灰引用括号、纸黄边界符号对应内容主题。正文使用适中行宽、编号章节、旁注、突出引文和下一篇入口。
- 关于：由首页便签展开为信纸；保留个人资料待补状态。联系：开放、留白的大标题与明确的联系方式占位，不伪造渠道。
- 沿用首页纸张、墨绿与低饱和色系。视觉层次通过字号、图幅、间距和细分隔建立；不改变 Chat 与场景。
- 交互：已有引用 ID、定位高亮、真实上一页与上下文问答保持；新增继续翻阅遵循同一导航历史。
- 响应式：桌面章节侧栏 sticky，手机流式目录；纸卡构图适配窄屏。动作减少偏好禁用细微过渡。

新增正文为设计示例，不代写个人事实或成果。真实素材及文章未确认，正式内容替换时需按篇幅重审排版。
