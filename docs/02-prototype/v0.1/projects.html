项目

每个项目固定四段：问题、我的贡献、当前状态、成果证据。 状态只有三种取值，避免“进行中”被读成“已完成”。资料不足的项目显式标出，不假装有成果。

演示状态：

还没有公开的项目

诚实空状态：不放假卡片、不放“敬请期待”的虚构条目。可以先去看经历或直接联系。

筛选为原型示意，点击暂不过滤

状态取值约定

状态含义页面表现
进行中正在做，已有可展示的阶段结果详情页可读，成果标注“阶段性”
已交付已完成并有可核实的结果详情页可读，证据链接有效
资料不足不能公开或证据不够只在列表出现，不进详情，不写成果
待你确认：PRD 7.5 里“项目四件套”的具体组成尚未定。原型先用“问题 / 贡献 / 状态 / 证据”，你可以改名或增删。
