经历

这一页承担两个职责：给访客看的自我介绍，以及给未来问答（R04）复用的结构化事实。 所以每一条经历都按“时间 / 角色 / 做了什么 / 可公开的证据”拆开，而不是写成一整段散文。

内容待你确认：下面的姓名、公司、时间、成果全部是占位示例。按 AGENTS.md 的约定，我不会替你编写真实经历； 评审通过后，你提供真实信息，我再按同一结构替换。
