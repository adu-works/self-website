移动端预览

下面是同一批页面在 390×760（约等于常见手机尺寸）里的样子，可以直接在框内滚动和点击。 原型用的是响应式布局，不是单独的手机版页面——直接把浏览器窗口拉窄也是同样效果。

如果框内是空白：部分浏览器用 file:// 打开时会限制 iframe。改用本地静态服务器打开，或直接把主窗口拉窄查看。

移动端的三个布局决定

  1. 导航折叠成“菜单”按钮：7 个入口在手机上一行放不下，展开为纵向列表。
  2. 所有多列网格变单列：项目卡、洞察面板、管理端左右栏都在 860px 以下改为单列。
  3. 差异视图保持等宽字体并允许换行：管理端的改动差异在手机上不做横向滚动，避免看不全就确认。
评审时值得专门看的是管理端在手机上的确认流程：如果你经常在手机上确认站长 Agent 的写入，这个布局是否够用？
