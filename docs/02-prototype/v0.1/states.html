可访问性检查项（原型已覆盖的部分）

  • 所有交互控件是原生 button / input / select，可用键盘 Tab 到达并操作。
  • 焦点有明显轮廓（试着按 Tab 看看）。
  • 导航当前页用 aria-current="page" 标记；管理端分区用 aria-selected。
  • 错误提示与正文同色系文字，不只靠颜色区分，配合“失败/无写入”等文字说明。
  • prefers-reduced-motion 下关闭骨架屏动画。
