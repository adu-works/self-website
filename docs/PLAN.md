## 推荐取舍与待确认

| 项目 | 当前建议或状态 |
|---|---|
| 首版售卖 | 标价商品 + 微信人工成交，不接网站支付，不自动发货 |
| 会员管理 | 先做后台客户与逐商品权益，不要求买家先注册网站 |
| 付费阅读 | 飞书指定账号只读授权；先验证实际账号能力，再确定资源结构 |
| 到期 | 后台列待撤权，人工到飞书处理并记录；不承诺实时自动撤权 |
| 防复制 | 开启实际可用的复制/下载等限制，明确无法杜绝截图和已读内容传播 |
| 付费 Skill | 建议暂缓以避免多一条内容输出通道；用户尚未明确取消此前需求 |
| 公共 AI 与归航 | 只用公开内容；保留完整 Chat 还是改搜索/AI 接入仍待确认，原型不改 |

商品实际价格、固定期限还是长期权益、微信资料、每晚处理时段及退款说明可在正式售卖前补齐。飞书必须先验证外部买家账号授权、跨商品隔离、撤权及安全限制，不能只凭文档保证全部可用。

## 建议开发顺序与唯一任务清单

全部未开始，整体方案获明确批准后才进入 G4。旧自动支付、订阅通知与付费 API 不作为当前默认实现；它们是否后续加入由实际运营需求决定。

- [ ] M0：用隔离测试文档与两个外部身份验证飞书可用性；评审商品卡片、微信弹窗与后台待办小样。真实外部邀请另按明确授权执行。
- [ ] M1：站长认证、公开内容编辑、版本、预览、发布与撤回；主站、详情、专题、社媒与返回关系。
- [ ] M2：商品管理、公开介绍与价格、微信咨询弹窗；内部飞书资源字段不出现在公开接口。
- [ ] M2：客户档案、订单权益快照、人工核实收款、交付记录和到期清单；验证续购、退款和重复登记。
- [ ] M3：按确认方式交付访客公共 AI；不收录飞书付费正文，不默认开发付费 Skill。
- [ ] M4：站长内容 Agent 提案与确认；不自动确认到账、退款、发微信或改变飞书权限。
- [ ] M5：迁移火星体验、按确认结果处理归航落点；检查手机、键盘、弱网、备份与恢复。
- [ ] M5：补真实商品与运营资料，用测试订单走通人工交付及到期流程；展示预览后确认正式发布。

原 22–32 天估算不适用。确定公共 AI 的交付范围并完成飞书试点后重估；删自动支付能省开发，但人工处理是持续运营成本，不能忽略。
