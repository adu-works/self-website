## 建议开发顺序与唯一任务清单

全部未开始；以 v2.1 范围获明确批准为前提。先用标注 mock 开发，真实支付验证使用所选渠道的测试环境，不收真实款。

- [ ] M0：确定首版商业范围、一个支持的 AI 客户端及部署/支付可行性；补充会员、接入与归航落点小样评审。
- [ ] M1：站长认证、内容版本、Markdown 编辑、预览、发布、撤回和恢复；完整网页阅读、专题与社媒。
- [ ] M2：访客账号、套餐、订单与权益；验证支付通知、续费、取消、退款和到期，前端不能伪造权益。
- [ ] M3：只读内容 API、文章 AI 开关、令牌创建/撤销、每账号额度与权限测试；先用普通请求证明修改 Skill 也不能越权。
- [ ] M3：一个客户端的 Skill 与连接工具；验证令牌保存、公开/付费片段查询、引用与失败恢复。远程 MCP/OAuth 根据客户端需要另行确定，不同时铺开。
- [ ] M4：站长 Agent 只读工具、提案、差异确认、保存草稿与发布；不增加支付或改权限工具。
- [ ] M5：迁移火星与归航，按批准方案处理落点；手机、慢网、无障碍与无 3D 降级。
- [ ] M5：补真实内容及运营配置，做权限、限流、备份恢复和完整购买链测试；展示具体预览后确认正式上线。

如果决定保留站内公共 Chat，再加入站长模型预算、匿名滥用控制和公开资料回答评估。Skill 交付必须标明已验证客户端，不能把“所有 AI 通用”列为未经证明的承诺。
