# 05 · 站长 Agent 与开源复用

> v2.0 · 待评审。推荐使用 Vercel AI SDK，业务权限与执行规则由本站控制。

v2.2 影响提示：这里是站长内容 Agent，不自动收款核实、退款、发微信或改变飞书授权。客户与订单管理使用确定性后台表单；付费 Skill 候选见模块 04，当前建议暂缓。

## 它帮你做什么

你可以说：“把这些笔记整理成文章”“把这个项目的进展补充到现有介绍”“把这篇文章恢复成上一个版本”。Agent 先读取你授权给后台的材料，指出缺失信息，再给出具体修改。缺少个人事实就留待补，不自行编造履历或成果。

右侧提案卡展示目标、依据、旧内容、新内容、阅读权限、影响页面和按钮。你可以继续修改、取消、保存草稿；发布是独立操作，预览后确认。对话中一句“好”不作为确定的发布授权，使用明确操作按钮绑定当前提案。

首版范围：单篇文章新建和修改、项目介绍修改、恢复旧版为草稿。站长能用普通后台管理专题、社媒、阅读权限；Agent 暂不修改这些敏感设置。也不执行 shell、不改代码、不删库、不批量发布、不发消息或操作公众号。

## 开源项目怎么选

| 候选 | 核对到的能力 | 本项目判断 |
|---|---|---|
| Vercel AI SDK | 模型适配、流式聊天、结构化工具参数、工具审批；Apache-2.0 | 最贴合网站问答与有限内容工具，建议直接依赖，自己写业务工具 |
| OpenAI Agents SDK（JS） | 工具、人工介入、会话、追踪、多 Agent；MIT，支持多供应商扩展 | 能用，但当前不需要交接与复杂编排；暂不叠加第二套框架 |
| Codex SDK | 包装 Codex CLI，通过子进程交换事件，支持线程及结构化输出；Apache-2.0 | 适合开发网站时用；拿来做文章后台会额外引入运行环境与权限范围，不作为网站运行时 |

结论是“复用库和接口，借鉴审批体验”，不用复制整个仓库再删。以后确实需要 Agent 改代码时，另建隔离的开发环境并重新评审权限，不偷偷扩展内容 Agent。

2026-09-20 阅读了以下一手资料：[AI SDK 工具与审批源码文档](https://github.com/vercel/ai/blob/main/content/docs/03-ai-sdk-core/15-tools-and-tool-calling.mdx)、[AI SDK 许可](https://github.com/vercel/ai/blob/main/LICENSE)、[Agents SDK README](https://github.com/openai/openai-agents-js)、[Codex TypeScript SDK](https://github.com/openai/codex/blob/main/sdk/typescript/README.md)。这是方案适配判断，未进行三套框架性能对比。

注意：当前 AI SDK 主分支文档已使用 `toolApproval`，旧 `needsApproval` 被标为弃用。实际开发先选稳定发行版并锁版本，按该版文档实现；不能把主分支代码当作已经安装的 API。开源代码复用时保留相应许可与声明。

## 模型与程序各做什么

模型做理解、整理与生成建议。程序做登录检查、读取、参数校验、差异计算、保存与发布。首版一个 Agent 就够；最多有限轮只读工具调用，达到上限把可见结果交给你，不无限循环。

模型工具只提供 `readContent`、`searchContent`、`proposeChange`。提案结果由服务器校验并交给浏览器预览；生成提案本身不改变文章。访客与站长使用不同入口、不同工具集。

审批不只靠 SDK 的聊天消息。浏览器确认时调用本站 `POST /api/admin/proposals/:id/confirm`，服务器检查站长身份、提案内容摘要、基础版本、有效期和是否已执行。成功在同一事务中写新版本与操作记录。同一提案确认两次只执行一次；旧提案不能覆盖刚编辑的新内容。

`proposals` 保存提案、基础版本、状态和到期时间；`operations` 保存执行目标、结果及重复请求标识。提案状态为待确认、已取消、已过期或已执行。初次确认只保存草稿；发布走内容管理模块的单独确认。登录过期后重新登录也不能自动继续执行。

请求断开时查询 `GET /api/admin/operations/:id` 核实结果，返回“待核实”而非诱导重复点击。失败明确哪些步骤没有完成；不要让模型自行判断写入是否成功。站长会话与提案是私有后台数据，可清理会话；执行记录保留必要审计信息，不记录 Key，备份保留策略在上线检查时落实。

## 怎样检查

让材料里包含恶意指令，确认不能调用不存在的工具；未登录伪造确认、过期确认、修改提案后重放确认均失败。检查取消、重复确认、版本冲突、断网核实、恢复草稿；验证模型不可用时普通编辑仍可发布。
