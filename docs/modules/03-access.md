# 03 · 付费订阅与内容权限

> v2.1 讨论稿 · 2026-09-20 · 用户提出付费订阅目标；上线范围、售卖方式与以下实现建议待确认，未开始开发。替代 v2.0 的“公众号通用码作为主要门槛”建议。

## 推荐方向

公开文章负责让读者了解你的内容质量；付费内容由账号的订阅权益控制。公众号用于更新通知、免费资料或限时活动，不作为付费会员身份。订阅者可以在网页阅读，并按授权让自己的 AI 查询内容；无需为了读文章先安装 Skill。

| 方式 | 适合的用途 | 不能承担的事情 |
|---|---|---|
| 公众号关键词回复通用码 | 引流、免费资料领取、低门槛活动 | 无法可靠识别付款人、续费、到期与退款 |
| 支付后一次性兑换码 | 外部售卖渠道接入的过渡方式 | 不能把码当永久身份；应兑换到账号并防重复使用 |
| 账号 + 订阅权益（推荐） | 持续更新的会员内容、跨设备阅读与 AI 接入 | 仍不能防止用户复制已经读取的内容 |
| 按专题一次性购买 | 已完成的课程或资料合集 | 不应包装成需要持续续费的服务，除非确有持续价值 |

持续付费需要持续更新、可用的检索与明确服务范围。若主要出售固定文章包，单次购买更直接。首版建议一个套餐，避免会员等级、积分和复杂优惠。月/年、自动续费或到期手动续费待决定，未授权接支付或收费。

## 参考站到底用了什么

JavaGuide 公开组件明确提示关注公众号后回复验证码，并以浏览器状态和可见高度控制阅读。能确认它有这套阅读引导；不能由此推断它的全部商业产品或证明转化效果优秀。[源码](https://github.com/Snailclimb/JavaGuide/blob/main/docs/.vuepress/components/unlock/UnlockContent.vue)

小林官网有公众号回复关键词领取资料；其 MewCode 项目页另有“支付购买之后拿到兑换码”的说明。因此免费引流与付费交付应分开看。CS-Base 未提供可确认的付费权限后台，不能说两站的后台都相同。[公众号资料](https://xiaolincoding.com/)、[付费项目说明](https://xiaolincoding.com/project/mewcode.html)。核对日期 2026-09-20，未实际购买或兑换。

## 用户怎样使用

看试读 → 查看套餐及权益 → 登录账号 → 支付 → 服务端确认到账 → 会员中心显示有效期 → 网页读全文，或创建自己的内容访问令牌并安装 Skill。Skill 可公开下载，不含私人令牌或付费正文；购买的是内容服务权限。

会员中心提供订单、订阅期限、续费/取消入口、接入说明、访问令牌列表和撤销按钮。令牌不是模型厂商 API Key，不提供模型额度。用户的模型费用仍由其原有 AI 服务承担；普通 AI 订阅是否支持工具执行取决于客户端。

标题、摘要、试读与公开目录由站长指定。付费网页正文、图片、搜索结果和 API 统一检查订阅权限，不在 HTML、预加载数据、公开仓库、RSS 或共享缓存里提前发出全文。站长手工编辑始终可用。

## 权限分成三层

1. 发布状态：草稿与撤回内容仅后台可见。
2. 网页阅读：公开或指定套餐可读。账号登录本身不代表已经付费。
3. AI 内容接口：文章另设允许 AI 使用及允许返回范围；默认付费内容不开放，站长明确勾选后，满足套餐与令牌范围才可访问。

本站公共 AI（若保留）始终只有公开资料；订阅者自己的 AI 可以通过授权接口读取允许开放的付费片段。这是当前对用户“AI 只用公开内容，但 Skill 可用付费内容”的解释，需用户确认。若希望任何第三方 AI 都接触不到付费内容，则不能同时提供付费内容 Skill。

网页会员不获得管理员权限。内容 API 永远只读，不共用站长工具、密钥或会话；不能通过令牌创建文章、修改订阅或购买服务。

## 支付与授权怎样保持一致

建议使用符合实际经营地区和收款资格的托管支付页面，不自建银行卡采集。不预先指定 Stripe 或国内渠道；先确认面向国内还是海外及可用商户资质，再验证渠道能力。技术方案不视为对平台准入、税务或法规的结论。

支付返回页只展示处理状态，不能凭 URL 的“成功”给权限。服务端验证支付通知签名、订单归属、套餐、金额和币种，按事件 ID 去重；处理重复、延迟及乱序通知，必要时向支付方核实最新状态并定期对账。支付与权益的分离可参考 [Stripe 订阅通知](https://docs.stripe.com/billing/subscriptions/webhooks)，不表示已选该平台。

| 事件 | 建议权益行为，商业规则待确认 |
|---|---|
| 首次支付确认 | 激活对应套餐至服务端记录的到期时间 |
| 续费成功 | 按支付方确认的服务区间更新，不盲目重复加时 |
| 用户取消自动续费 | 本期已付权益保留到期；取消不等于立即退款 |
| 支付失败 | 不新增服务期；已有付费期继续，到期停止新访问 |
| 退款或争议 | 按明确退款规则撤销相关权益或转人工核查，不根据猜测扣除其他订单权益 |
| 到期或站长撤销 | 网页与 API 同时停止后续付费访问，旧令牌也不能绕过 |

建议增加账户、订单/订阅、套餐权益、支付事件记录和访问令牌数据。支付数据和敏感配置不放公开仓库。所有内容请求重新核对当前权益；不能只在生成令牌那天检查一次。

## 验收必须覆盖

支付成功但通知延迟、伪造返回地址、重复通知、乱序通知、续费失败、取消续费、退款、到期、撤销令牌、越套餐读取、两用户缓存隔离。网页与 API 结果一致。已交付的片段不能远程收回，这是产品边界，不用“防盗链”假装解决。
