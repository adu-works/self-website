# 02 · 内容管理与发布

> v2.0.1 · 2026-09-20 补充专题编辑，待评审。目标：不用改代码也能更新网站，不依赖 AI 才能写文章。

## 你怎样管理内容

后台分为文章、项目、专题、个人资料与社媒。文章列表可以按草稿、已发布、已撤回筛选，也能搜索标题。新建文章后，左侧编辑，右侧用真实网站版式预览。

首版采用 Markdown 编辑加工具栏：插图、代码、标题、引文、表格都有入口；可以导入单个 `.md` 文件。这样写作与备份简单，避免为首版造一个完整的 Notion。导入后先预览，未知语法明确提示，不执行 HTML 脚本、MDX 或文件里的代码。项目则用固定字段和内容段落编辑，便于保持作品详情设计。

草稿自动保存，显示“保存中 / 已保存 / 保存失败”。自动保存只影响草稿，不改变线上内容。发布前检查标题、链接、摘要、封面说明、专题、阅读权限和是否允许 AI 使用；右侧明确显示将公开的内容。你点发布才生效。

| 操作 | 结果 |
|---|---|
| 保存草稿 | 只有站长可见；原来已发布的版本继续对外展示 |
| 发布 | 展示预览和差异后确认；更新线上版本与搜索段落 |
| 撤回 | 确认后停止正文访问及 AI 检索；历史版本留在后台 |
| 恢复旧版 | 先恢复成新草稿，检查差异后再发布，不抹掉新历史 |
| 修改公开为需解锁 | 明确提示之后的访问将受限；无法收回访客已下载的公开内容 |

首版不提供永久删除和批量发布。误操作优先通过撤回、恢复解决。修改权限、专题和个人资料同样有预览确认。未保存就离开时提醒；已保存的草稿可在重新登录后继续。

专题编辑提供简介、适合读者、阅读建议、文章选择与排序，排序支持按钮操作，不只依赖拖拽。专题页和文章中的专题导航共用这份顺序，不手工维护两份目录。选入草稿时后台标注“发布后才对外显示”；公开预览自动过滤草稿与撤回内容。此项来自 CS-Base 内容组织的启发，不增加多层分类系统。

## 内容保存成什么

一篇内容有固定身份和多个版本。标题、摘要、slug、正文、阅读方式、AI 开关随版本保存；发布指向其中一个版本。Markdown 是编辑与导入形式，保存时转换成有稳定 ID 的安全正文块；原始 Markdown 一并保留，正文块负责页面显示和引用。未改动的段落保留 ID，新段落分配新 ID，不用段落序号充当永久链接。

建议数据：`contents` 保存身份与草稿/发布指针；`revisions` 保存不可变版本；`sections` 保存可检索段落及版本；`series` 保存专题和文章顺序；`assets` 保存素材、来源与权限。个人资料与社媒作为独立的结构化设置，走同样的版本确认服务。提案与执行记录见 Agent 模块，解锁数据见权限模块。

每次发布先完成正文解析与校验，再在一个数据库事务中写入版本、段落和发布指针。任何一步失败都不生效。首版正文和查询结果按请求读取数据库，不引入整站发布快照、独立队列或后台发布 worker，换取更容易理解和核查的流程。以后内容量或流量增长，再用测量结果决定缓存与异步索引。

图片上传校验类型和大小，保存替代文字、来源与许可。受限文章的专属图片/附件放私有存储，通过权限检查后提供短时链接；试读图另行标记公开。导入 Markdown 不自动下载其中任意远程地址，站长明确上传或选取素材。未引用素材清理由站长检查后操作。

## 接口与失败处理

| 接口提案 | 输入和结果 | 谁能用 |
|---|---|---|
| `GET /api/content/:slug` | 返回允许阅读的正文或公开试读；不带草稿 | 访客，由服务器判权限 |
| `GET /api/search` | 关键词、专题；返回可读片段 | 访客 |
| `PUT /api/admin/content/:id/draft` | 内容、基础版本；返回新版本 | 站长 |
| `POST /api/admin/content/:id/publish` | 已检查的版本、确认标识、重复请求标识 | 站长 |
| `POST /api/admin/content/:id/withdraw` | 当前版本和确认标识 | 站长 |

管理功能从第一条写接口开始就必须验证站长身份，不能等阅读解锁模块完成才补认证。所有输入服务端校验。两个窗口同时修改返回版本冲突，让你比较，不覆盖。网络中断先查询操作结果，不能把“没收到响应”当成未发布；重复确认返回同一执行结果。普通编辑和 Agent 最终调用同一个内容服务，不能存在另一条绕过确认的写入路径。

## 怎样检查

用示例文章走完保存、预览、发布、撤回和恢复；让发布中途失败，确认线上仍是原版；两个窗口制造冲突；断网后查询结果；未登录直接请求写接口必须失败。检查站长关闭 AI 后仍能独立完成整条发布链。
