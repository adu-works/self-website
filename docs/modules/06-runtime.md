# 06 · 火星体验、工程底座与上线

> v3.3 · 待评审。主站先服务阅读与购买，3D 为可选作品。

## 主站与实验分开

默认入口直接打开个人首页，不再播放开场、要求挖宝或填写模型 Key。静态原型入口是 `dist/index.html`，控制器为 `personal.js`，样式为 `personal.css`。原场景在 `explore.html`，退出主站作品列表，仅保留历史直接链接；不是另一套并行网站版本。原场景中的旧配置和归航页仍是历史交互演示，不代表正式 AI 接入方案，页面保留返回新版首页的固定链接。

将来重新批准实验时，可评估独立 `/explore` 路由，彻底移除旧模型配置与旧主站路由，结束时回新版首页。本轮决定不在首版迁移实验；不让维护游戏拖延内容、商品和客户管理。

公开 Chat 原型为固定内容模拟，不收集 Key。真正的公共模型调用方式、额度和费用，以及是否用 Skill 替代，需另行确认。商品、订单、客户与 Agent 原型均仅改变内存，刷新清空，没有认证、支付或飞书操作能力。

## 技术怎么组成

当前没有生产后端。原型用 HTML、CSS、JavaScript；本地 `python3 -m http.server` 只负责提供静态文件，不是业务后端。

2026-09-21 用户授权按项目适合程度选型，本轮确定 TypeScript 全栈方向。具体工程方案仍待 G3 评审。

| 部分 | 推荐选择 | 职责 |
|---|---|---|
| 前端 | Next.js / React + TypeScript + CSS | 页面、交互与服务器渲染 |
| 后端 | Next.js Route Handlers + Node.js + Zod | 校验输入、权限、内容、订单与 Agent 服务 |
| 数据层 | PostgreSQL + Drizzle ORM / SQL 迁移 | 数据读写、事务与表结构变更 |
| 托管服务 | Supabase Auth / PostgreSQL / Storage | 托管身份、数据库和附件，本站服务端仍检查权限 |
| 模型 | Vercel AI SDK + 有限工具流程 | 模型适配、流式响应和提案，不引入多 Agent 编排 |
| 检查 | TypeScript、ESLint、Vitest、Playwright | 类型、代码检查、逻辑/数据库集成及页面操作 |

一个 Node.js 应用同时提供页面与 API，无需额外部署 Python 服务；前后端共享安全的契约，不共享秘密和数据库访问代码。Sites 继续承载静态原型，正式应用需要服务端环境；不限定必须部署到 Vercel。具体地区、预算、网络和流式限制先验证再锁定托管商与依赖版本。

单体按功能模块组织，不建微服务、独立向量库或消息队列。后台和 Agent 复用同一业务服务。请求流程、认证和部署边界见 [功能实现方案](../IMPLEMENTATION.md)。

## 加载与降级

先显示可读主站，进入探索才下载大型 3D 资源。离开场景释放渲染、监听器和显存。手机减少细节，WebGL 不可用显示“直接阅读 / 前往 Chat”；尊重减少动效设置，不强制声音。

首版正文请求不走共享内容缓存，以简化撤回和权限变更的一致性；图片与静态代码按公开/私有分开处理。公开页面仍提供标题、摘要与搜索引擎所需信息。若以后加缓存，必须先证明受限全文不会跨用户共享。

## 上线前必须真的做的事

- 用示例数据通过全流程，再按你提供的材料替换；不能把 mock 项目成果当真。
- 390px 手机和 1440px 桌面检查阅读、导航、Chat、解锁；检查键盘、200% 放大和减少动效。
- 核实部署区域实际可达、模型调用成功、权限隔离、流式停止与超时。费用包括网站、数据库、存储、流量及站长模型；公共 AI 的费用归属在交付方式确认后确定，不默认收集访客 Key。
- 数据库和私有附件定期备份，至少做一次恢复演练。上线前记录备份保留时间、恢复步骤与旧应用版本；不把“有备份开关”当作可恢复。
- 预览与正式环境隔离，用环境变量保存秘密；公开仓库只放源码和假配置模板。
- 部署前展示具体预览及检查结果，由你批准该次正式发布。回滚应用和恢复内容是两条独立路径，都要能操作。

预算、域名与地区在部署验证前补齐；现在不要求你为了看方案就提供真实文章、履历或所有账号。
