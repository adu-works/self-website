# 07 · 自己的书籍与公开协作

> v1.0 · 2026-09-21 · 用户明确要求新增栏目，原型 v2.1.0 待评审，正式功能未开始。

## 读者怎么用

导航和首页提供“书籍”入口。书籍页说明书名、简介、作者、写作/出版状态和目录，再进入章节。没有真实出版资料时只展示“示例书稿”，不虚构出版社、ISBN、销量或发布日期。

章节宽屏采用三栏：左侧全书目录、中间正文、右侧本章小节。手机把两种目录分别折叠。章节底部有上一章、下一章；第一章不伪造前一章，最后一章明确结束并提供书籍入口。返回按钮仍回真实来路，直接打开章节则回书籍栏目。

标题右边是两个带名称的按钮：

| 按钮 | 去向 | 说明 |
|---|---|---|
| 查看源文件 | GitHub `blob/{publishedCommit}/{chapterPath}` | 实际发布版本的本章 Markdown，不是仓库首页 |
| 编辑此章 | GitHub `edit/{branch}/{chapterPath}` | 指向维护分支，提示其可能领先于阅读版本；登录后按 GitHub 提示提交 PR，网站不会直接写入 |

仓库维护者的 GitHub 页面可能允许直接提交；正式协作建议采用分支保护和 PR 审核。这是工程建议，本轮未修改仓库权限。

## 和付费内容怎样区分

公开源码书籍允许读者查看和复制正文，不能同时承诺防复制。当前示例全部公开；付费商品和飞书正文沿用模块 03，绝不把付费正文放进公开仓库或静态构建。未来若一本书只有部分章节公开，仅公开章节可显示源码和编辑按钮，其他部分只显示已批准公开的介绍与购买说明。

不因新增书籍栏目自动增加 PDF 下载、实体书销售或会员订阅；真实书名、内容、出版状态和分发范围之后由本人提供。

## 内容怎样维护

书与章节使用稳定 ID，章节记录标题、顺序、分节 ID、公开状态、仓库、分支和源文件路径。所有链接由可信配置生成，不接受读者输入任意仓库地址。

公开书稿采用 Git 为事实来源，避免后台和 Git 两套正文互相覆盖。未来站长后台与 Agent 若编辑公开书稿，应生成分支/PR 提案并展示差异；不能直接覆盖主分支。这部分属于正式实现方案，未在当前演示后台接入。

当前原型示例源文件在 `prototype/books/independent-site/`。修改后运行 `node prototype/build-books.mjs`，生成 `prototype/dist/books-data.mjs`；书籍页面读取生成数据。生成器仅支持本次用到的标题、小节和普通段落，文字转义后呈现，不执行书稿 HTML。正式实现再选择成熟的 Markdown 渲染与清理方案。

PR 提交不会自动发布。当前需要维护者合并、重新生成、检查并发布 Sites。正式方案建议受保护主分支触发构建，先检查目录与链接，审核预览后发布；不在本轮擅自设置自动发布。

## 怎么验收

- 从书籍页进入各章、切换上下章、跳到小节；首尾和缺失章节都有正确状态。
- 每章的源文件/编辑链接指向真实且同一份文件，普通访客不能直接修改站点。
- 在 1440px 与 390px 检查目录、标题按钮和正文；手机不横向溢出。
- 示例与真实出版状态区分；付费内容不进入公开 Git 或静态文件。

## 每本书的仓库与权利安排（2026-09-21 补充建议）

用户希望积累自己的出版物和长期收入。建议一本正式书稿一个主仓库，网站只配置书籍、章节、仓库和允许公开的内容版本，避免所有书与网站代码混在一起。此为方案建议，未创建新仓库或改变任何许可；当前示例仍在原型目录，不将示例冒充真实资产。

| 类型 | 主仓库 | 网站与协作 |
|---|---|---|
| 计划商业出版的完整书稿 | 默认私有，作者控制访问 | 仅发布明确选定的介绍/试读；不暴露私有源文件或编辑链接 |
| 决定公开协作的书 | 每书独立公开仓库，先确认内容许可 | 可以逐章查看、编辑并提交 PR |
| 配套代码 | 可放独立代码目录或配套仓库 | 代码许可与正文许可分别说明，不能用一个软件许可无差别覆盖书稿 |

GitHub 没有“同一公开仓库里某个文件夹私有”的保护方式。商业书需要公开试读 PR 时，可以另建只含获准试读的公开配套仓库；不能从含完整书稿历史的仓库直接转公开。网站构建只读取允许公开的导出内容，私有书稿和凭据不能打包进静态网站。

每书至少记录：作者署名、实际著作权人、年份/版本、内容许可、第三方素材授权、贡献者记录。仓库归属不等于著作权归属。版权声明有告知作用，不凭一句“所有权归我”消除共同作者或第三方权利；AI 示例也不在未审查实际创作贡献时宣称完整独占版权。

真实原创书稿可在确认权属后使用如下声明草案，不直接作为当前示例的最终法律条款：

> © [年份] 黄凌波。除另有标注及法律允许的使用外，正文与原创配图保留权利。公开试读不代表授权商业转载、再出版、翻译或改编。第三方内容及配套代码按各自许可处理。授权联系：[待补]。

如果希望开放改稿，需另配清楚的贡献规则：贡献者有权提交，保留其依法享有的权利，并明确授予维护者编辑、发布、商业出版及必要转授权的范围。大段增写、翻译和配图尤其要保留授权证据；PR 合并本身不是版权转让。具体规则应在接收真实贡献、签出版合同前由版权专业人士核对，不能把待讨论条款静默应用于已提交贡献。

## 与出版社合作的准备

可以联系正规出版社，不必机械地等到全部写完。建议准备选题简介、目标读者、完整目录、1—2 章成熟样章、差异化和预计完成时间，先问匹配的编辑；录用与报酬取决于具体评审和合同。已公开的内容及许可必须如实披露，不能再向出版社承诺与既有授权冲突的独占权。

收益按合同约定，可能是版税、稿酬等；出版不保证销量或持续收入，还会有修订、勘误与宣传成本。建议把它当作可长期经营的作品资产，而不是确定的被动现金流。

合同优先核对：授权的语言、地域、载体和期限；是否独家；版税按定价还是实际收入、退货扣减和结算周期；出版期限及未出版/停售后的权利回归；网站试读、飞书资料、电子书、音频、课程和翻译权是否保留。不要未经评估就授予全球、永久、所有媒介的全部权利。签约前应由熟悉出版合同的人核阅具体条款。
