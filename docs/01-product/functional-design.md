## 访客问答状态

未配置 → 配置并验证（原型模拟） → 空白 → 输入 → 等待 → 回答/无资料/错误/限流。等待时可停止；停止后不把未完成回答呈现为完整结论。建议问题来自实际公开内容，没有材料时不用虚构问题暗示已有项目。

离开 Chat 可通过“回收飞船 · 浏览主站”进入主站（本次设计）；主站重新打开 AI 时不重复探索，配置有效则继续会话，失效则保留问题并重配。

每条回答明确当前范围，引用至少显示标题与定位；访客点击引用后能查看对应段落并返回问题。跨项目问题提供“切换到全站问答”动作，不静默扩展查询范围。

原型使用预设回答，固定标注“模拟问答，未连接模型”。成品展示真实请求结果；任何“回答准确率”都必须来自实际评估记录。

## 管理提案状态

输入目标与材料 → 补充信息或生成提案 → 待检查 → 确认 / 取消。

- 用户修改要求后重新生成差异；之前的确认不延用。
- 执行前核对提案和内容版本；不一致则回到检查状态。
- 执行中禁止重复提交，但能查看进度。若连接中断，显示“结果待核实”，查询同一次操作，不能直接重新执行。
- 结果分别显示内容保存、站点发布、问答来源更新；某一步失败只说明该步失败，保留已经完成部分的事实。
- 恢复旧版先展示它将覆盖什么，再次确认；恢复失败保留当前版本与重试/排查路径。

### 提案卡示例（字段示意，不是真实用户内容）

| 字段 | 示例 |
|---|---|
| 操作 | 更新项目描述 |
| 对象 | 示例项目 A |
| 依据 | 站长刚提供并允许公开的说明 |
| 修改前 / 后 | 两段完整文本或逐字段差异 |
| 影响 | 项目详情及相关问答来源 |
| 内容版本 | 提案生成时的版本，用于识别后续冲突 |
| 动作 | 查看预览 / 修改要求 / 取消 / 确认发布 |

不把“确认发布”藏进发送消息动作；不以站长之前允许开发网站代替某次内容发布授权。

## 原型评审路径与产品验收区别

1. 首页 → 项目 → 证据 → 联系（R01/R02，A01）。
2. 同一项目提问 → 引用 → 原文 → 返回（R04/R05，A02）。
3. 无资料、跨范围、停止、错误和限流各演示一次（R04/R05，A02）。
4. 管理对话 → 修改 → 差异 → 取消，确认没有模拟内容变化（R06，A04）。
5. 另一提案 → 确认 → 部分失败 → 结果核实 → 恢复预览（R06，A04/A06）。
6. 手机、键盘、文本放大、减少动效走核心路径（R12，A05）。

G2 验证这些交互是否表达清楚；G4 才验证真实模型、认证、发布与版本恢复。不能用定时器演示代替工程验收。

## v1.1 交互修订

场景与聊天以[当前完整体验方案](../02-prototype/experience-spec-v1.1.md)为准：开炉门、三次锻打、取铲、地形越坡、五次铲土、开箱、配置、收票、开舱、登船、发射；搬炉和砸下分别触发。Chat 全屏会话区、会话历史（仅内存）、段落锚点及返回恢复。管理流程和权限边界沿用，全部模拟。

v1.1.1：搬起可撤回，R 放下后保留先前锻造进度；F 搬起、X 砸下、E 单次当前动作、G 辅助移动。禁用输入期间与长按重复触发。

v1.1.2（C024）：工具挂手；负重慢走；R 在当前前方安全位置放下，碰撞跟随新位置。归航按发射→轨道→大气层→着陆→开舱→出舱→伸展→视线转场执行，默认打开完整 Chat。重看与跳过仍回到 Chat；回收飞船再进入主站。

v1.1.3（C025）：[页面关系与返回矩阵](../02-prototype/navigation-audit-v1.1.3.md)。历史返回使用同一浏览器历史项；固定导航使用明确目的地。配置弹窗取消保留来源；恢复预览取消回版本记录；工作台输入与提案/结果可在页面往返后恢复。模型配置仍模拟，未扩张权限。

## v1.1.5 详情阅读修订

项目详情与文章保留既有 `section-0/1/2` 引用目标。章节目录在桌面固定于阅读侧栏，手机进入文档流。详情末尾提供下一项目/下一篇文章；该跳转创建正常历史记录，返回回到真实来源。上下文问答继续携带当前标题与范围。关于→联系返回关于。内容示例标记保留，联系方式未提供时不产生虚假链接。

## v1.1.6 社媒主页

姓名主标题是语义链接，目标为独立社媒页。社媒链接新标签页打开并带 noopener/noreferrer；空地址为普通占位行，不生成假链接。返回使用站内真实来源，直达链接无来源时返回主站。链接集中维护于 `dist/social-profile.js`。
