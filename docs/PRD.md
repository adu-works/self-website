# 黄凌波的个人网站 · PRD

> v3.0 讨论稿 · 2026-09-20 · 个人影响力与售卖方向重设计待评审，尚未开始正式开发。

## 这个网站做什么

网站同时承担两件事：让读者认识并持续关注黄凌波；让合适的读者了解并购买内容产品。主题不局限于技术，也包括生活认知、独立实践和商业赚钱。先用免费内容建立信任，再通过明确的商品介绍承接需求，不承诺收益。

首页直接展示个人介绍、精选文章、最近文字、商品与作品入口。访客不用玩游戏、登录或配置模型。原火星体验降为作品页内的可选交互实验，不再承担首页或购买前置流程。

商品明确展示介绍、目录、试读、价格、期限和交付说明，点击后打开微信咨询弹窗。微信人工成交、每晚集中处理，付费正文由飞书指定账号阅读；后台管理客户、订单和到期处理。公众号仅是传播窗口。

## 首版交付什么

| 模块 | 访客或你能够完成的事 | 具体设计 |
|---|---|---|
| 主站与阅读 | 看项目、读文章、按专题连续阅读、搜索、找到社媒 | [阅读设计](modules/01-reading.md) |
| 内容管理 | 写文章、导入 Markdown、预览、发布、撤回、恢复旧版本 | [管理设计](modules/02-editor.md) |
| 商品与购买管理 | 商品卡片、微信咨询、客户订单与期限管理、飞书人工交付 | [权限设计](modules/03-access.md) |
| 访客 AI | 只使用公开资料；网页 Chat 与公开 Skill 的交付形式待确认，付费接口建议暂缓 | [问答设计](modules/04-chat.md) |
| 站长 Agent | 整理材料和修改内容，先给差异，再由你决定是否执行 | [Agent 设计](modules/05-agent.md) |
| 火星体验与运行 | 可选作品实验；主站不加载 3D，手机、慢网仍能直接阅读 | [场景与工程设计](modules/06-runtime.md) |

既有首版要求包含访客 AI 和站长 Agent，不能把静态网站当作全部完成。商品与人工交付纳入本次设计；是否首版上线、访客 AI 是否改为 Skill 交付，需本轮确认；不能把提议直接当作替换授权。

商品与客户订单现已进入设计范围，上线批次待确认。暂不做站内在线支付、自动发货、自动续费、多管理员、评论社区、自动发公众号、Agent 改代码或代你操作其他平台。文章导入是你上传文件，不抓取别人的付费或受限内容。

## 已有基线与本轮影响

2026-09-20 用户明确要求围绕“个人影响力 + 售卖入口”重新设计。原型 v2.0.0 已据此制作，尚待视觉和流程评审；不把本次修改等同于正式开发获批。

- 主导航：首页、文字、作品、小店、关于；姓名和社媒入口使用“黄凌波”，社媒账号只用真实已知链接。
- 文字按技术与 AI、生活与认知、独立实践、商业与赚钱组织。文章详情有独立封面、导语、引文、分章和目录；商品详情有目录、试读与购买说明，不共用裸 Markdown 页面。
- 火星原型作为可选作品暂留，其原有动作不再是首页验收前提；是否保留到正式首版待评审。
- 公共 Chat 作为次级入口演示，不再要求访客填写模型 Key。是否正式接模型或改用公开 Skill 仍待明确，付费 Skill 暂缓是建议。
- “返回”回真实来源并恢复位置、筛选或会话；固定跳转明确标为“前往”。AI 引用可进入对应文章段落。
- 示例文章、商品、价格及订单明确标注。未收到的微信号、经历、社媒不编造。站长 Agent 只演示提案和确认，不执行真实写入。

## 新设计的取舍

推荐“网站商品展示 + 微信人工付款 + 飞书指定账号阅读 + 后台订单与权益记录”。公众号只作为宣传窗口。公开网页不包含付费正文或内部飞书资源，买家无需先注册本站会员；后台客户档案记录实际授权身份。

防护目标是限制复制、下载、分享与未授权访问，不承诺杜绝截图拍照。后台到期记录不等于飞书已撤权，必须有到期待处理清单和人工核验结果。详细流程见模块 03。

此前提出的付费内容 Skill 仍是历史产品意图；本轮更重视防复制和人工交付，因此建议暂缓付费 API，不视为用户已经取消。公共 AI 仍只使用公开内容；正式 AI 交付方式仍需明确确认；新版公开原型已移除 Key 入口。

建议用成熟 AI SDK 接入模型，网站自己控制权限和发布。人工编辑始终可用，模型故障不会让你无法管理网站。具体选择见 Agent 模块，不需要你挑技术库。

## 怎样算完成

1. 手机和电脑都能从首页找到文章、项目、社媒；详情版式与当前原型一致，键盘也能操作。
2. 你能用示例文章完成“编辑 → 预览 → 发布 → 修改 → 恢复”，不用改源码；取消不产生写入。
3. 商品公开页面不泄露付费正文、内部交付链接与买家信息；飞书按账号授权，撤权经过实际核查。
4. AI 能回答有依据的问题、说明不知道的内容，来源可定位；权限失效、访问超额、断网均有清楚出口；具体聊天验收按最终选定入口调整。
5. Agent 只能提出允许范围内的变更；确认后执行一次；旧版本冲突或登录过期时不会偷偷覆盖。
6. 首页直接可读，文章与商品可独立分享；不进入火星也能完成全部阅读和购买咨询任务。可选实验与主站加载隔离。
7. 开发交付可使用标注示例；以真实个人网站对外发布前，再替换并确认个人内容、费用和部署地址。

8. 站长能登记实收、买家身份、交付与到期，区分“到期”和“已撤权”；续购与退款不误伤其他有效权益。
