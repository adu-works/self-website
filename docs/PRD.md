# 黄凌波的个人网站 · PRD

> v2.2 讨论稿 · 2026-09-20 · 微信人工成交与飞书交付调整待评审，尚未开始正式开发。

## 这个网站做什么

让访客认识黄凌波、阅读文章与项目。新增目标是把部分内容做成标价商品，网站展示、微信私下成交、每晚人工处理，付费正文放飞书按买家授权。后台记录客户、订单、期限与交付待办。此前付费 Skill 建议暂缓，尚待确认。推荐取消网站访客模型 Key 入口，但是否替换原有完整 Chat 尚待确认。你可以自己编辑内容，或让站长 Agent 整理材料、提出修改，检查后再保存、发布。

火星探索是有记忆点的入口：打造铲子、挖宝、获得船票、乘火箭返回地球，进入完整聊天页。访客也能直接进入主站，阅读不需要玩游戏、登录或配置模型。

|---|---|---|

| 商品与购买管理 | 商品卡片、微信咨询、客户订单与期限管理、飞书人工交付 | [权限设计](modules/03-access.md) |
| 访客 AI | 只使用公开资料；网页 Chat 与公开 Skill 的交付形式待确认，付费接口建议暂缓 | [问答设计](modules/04-chat.md) |
| 站长 Agent | 整理材料和修改内容，先给差异，再由你决定是否执行 | [Agent 设计](modules/05-agent.md) |

既有首版要求包含访客 AI 和站长 Agent，不能把静态网站当作全部完成。商品与人工交付纳入本次设计；是否首版上线、访客 AI 是否改为 Skill 交付，需本轮确认；不能把提议直接当作替换授权。

商品与客户订单现已进入设计范围，上线批次待确认。暂不做站内在线支付、自动发货、自动续费、多管理员、评论社区、自动发公众号、Agent 改代码或代你操作其他平台。文章导入是你上传文件，不抓取别人的付费或受限内容。

## 已有基线与本轮影响

下面的完整 Chat、模型配置与船票关系来自之前已明确的方向。本轮提出改用 Skill，仅重审受影响的入口与数据流，其余视觉和导航要求保留。

- 姓名使用“黄凌波”，首页姓名可点击进入社媒目录。支持 GitHub、小红书、抖音、知乎、Bilibili、LinkedIn、X。你在本地文档提出同时展示 Lingbo-Huang 和 adu-works；建议分别标注个人与工作账号，标签待核实，其余链接不猜测。
- 当前原型 v1.1.6 是视觉与交互基线。保留首页以及项目、文章详情的设计完成度；正文不能退回统一的裸 Markdown 页面。
- 火星可跳过。挖土、打造、开门分别操作；按钮与快捷键一致；搬炉后能放下，角色能负重行走。道具跟随手部，移动服从地形。
- 归航有火箭、大气层、落地、开舱、出舱和自然伸展。镜头绕至肩后，再顺目光切入完整 Chat，不穿过头部。Chat 可再进入主站。
- “返回”回到真实来源并保留阅读位置、筛选或对话；固定目的地写成“前往主站”等明确名称。
- 普通阅读与 AI 配置分开；访客 Key 和站长 Key 分开；管理员写操作必须展示具体变更并确认。
- 依照你对原 PRD 的修改，先用明确标注的 mock（示例）数据完成搭建，个人经历、项目、文章、其他社媒、语言及运营资料之后补充。资料未齐不阻止工程开发；未经确认的示例不冒充真实经历。

## 新设计的取舍

推荐“网站商品展示 + 微信人工付款 + 飞书指定账号阅读 + 后台订单与权益记录”。公众号只作为宣传窗口。公开网页不包含付费正文或内部飞书资源，买家无需先注册本站会员；后台客户档案记录实际授权身份。

防护目标是限制复制、下载、分享与未授权访问，不承诺杜绝截图拍照。后台到期记录不等于飞书已撤权，必须有到期待处理清单和人工核验结果。详细流程见模块 03。

此前提出的付费内容 Skill 仍是历史产品意图；本轮更重视防复制和人工交付，因此建议暂缓付费 API，不视为用户已经取消。公共 AI 仍只使用公开内容；模型 Key 入口与归航 Chat 的改变也仍需明确确认。

建议用成熟 AI SDK 接入模型，网站自己控制权限和发布。人工编辑始终可用，模型故障不会让你无法管理网站。具体选择见 Agent 模块，不需要你挑技术库。

## 怎样算完成

1. 手机和电脑都能从首页找到文章、项目、社媒；详情版式与当前原型一致，键盘也能操作。
2. 你能用示例文章完成“编辑 → 预览 → 发布 → 修改 → 恢复”，不用改源码；取消不产生写入。
3. 商品公开页面不泄露付费正文、内部交付链接与买家信息；飞书按账号授权，撤权经过实际核查。
4. AI 能回答有依据的问题、说明不知道的内容，来源可定位；权限失效、访问超额、断网均有清楚出口；具体聊天验收按最终选定入口调整。
5. Agent 只能提出允许范围内的变更；确认后执行一次；旧版本冲突或登录过期时不会偷偷覆盖。
6. 火星主线、直接进入主站、重看归航、返回来源均走通；归航落点变更需确认，关闭动效仍能完成任务。
7. 开发交付可使用标注示例；以真实个人网站对外发布前，再替换并确认个人内容、费用和部署地址。

8. 站长能登记实收、买家身份、交付与到期，区分“到期”和“已撤权”；续购与退款不误伤其他有效权益。
