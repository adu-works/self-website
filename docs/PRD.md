# 黄凌波的个人网站 · PRD

> v2.0 · 2026-09-20 · 本次修订待评审，尚未开始正式开发。

## 这个网站做什么

让访客认识黄凌波、阅读文章与项目，也可以带着自己的模型 API Key 向网站提问。你可以自己编辑内容，或让站长 Agent 整理材料、提出修改，检查后再保存、发布。

火星探索是有记忆点的入口：打造铲子、挖宝、获得船票、乘火箭返回地球，进入完整聊天页。访客也能直接进入主站，阅读不需要玩游戏、登录或配置模型。

## 首版交付什么

| 模块 | 访客或你能够完成的事 | 具体设计 |
|---|---|---|
| 主站与阅读 | 看项目、读文章、按专题连续阅读、搜索、找到社媒 | [阅读设计](modules/01-reading.md) |
| 内容管理 | 写文章、导入 Markdown、预览、发布、撤回、恢复旧版本 | [管理设计](modules/02-editor.md) |
| 阅读权限 | 免费文章直接读；指定文章通过公众号验证码解锁 | [权限设计](modules/03-access.md) |
| 访客 AI | 自带模型配置；完整对话；点击引用定位原文 | [问答设计](modules/04-chat.md) |
| 站长 Agent | 整理材料和修改内容，先给差异，再由你决定是否执行 | [Agent 设计](modules/05-agent.md) |
| 火星体验与运行 | 保留当前原型体验；手机、慢网、无 3D 时仍可用 | [场景与工程设计](modules/06-runtime.md) |

正式首版必须包含访客 AI 和站长 Agent，不能把静态网站当作全部完成。公众号解锁是本次新增设计，具体方式仍待你选择。

首版暂不做付费订阅、多管理员、评论社区、商品订单、自动发公众号、Agent 改代码或代你操作其他平台。文章导入是你上传文件，不抓取别人的付费或受限内容。

## 已经确定的要求

- 姓名使用“黄凌波”，首页姓名可点击进入社媒目录。支持 GitHub、小红书、抖音、知乎、Bilibili、LinkedIn、X。你在本地文档提出同时展示 Lingbo-Huang 和 adu-works；建议分别标注个人与工作账号，标签待核实，其余链接不猜测。
- 当前原型 v1.1.6 是视觉与交互基线。保留首页以及项目、文章详情的设计完成度；正文不能退回统一的裸 Markdown 页面。
- 火星可跳过。挖土、打造、开门分别操作；按钮与快捷键一致；搬炉后能放下，角色能负重行走。道具跟随手部，移动服从地形。
- 归航有火箭、大气层、落地、开舱、出舱和自然伸展。镜头绕至肩后，再顺目光切入完整 Chat，不穿过头部。Chat 可再进入主站。
- “返回”回到真实来源并保留阅读位置、筛选或对话；固定目的地写成“前往主站”等明确名称。
- 普通阅读与 AI 配置分开；访客 Key 和站长 Key 分开；管理员写操作必须展示具体变更并确认。
- 依照你对原 PRD 的修改，先用明确标注的 mock（示例）数据完成搭建，个人经历、项目、文章、其他社媒、语言及运营资料之后补充。资料未齐不阻止工程开发；未经确认的示例不冒充真实经历。

## 新设计的取舍

文章默认公开，仅由你选中的文章设置解锁。标题、摘要和你指定的试读内容公开，正文由服务器判断是否可读。建议用公众号关键词回复通用码起步，不要求访客注册账号。这是吸引读者关注的手段，不能证明持续关注，也不能阻止拿到码的人转发。

建议 AI 首版只回答公开文章与公开项目。即使访客解锁了文章，也暂不把受限正文发送给其选择的模型供应商。这样隐私边界清楚；若你希望解锁后也能问该文章，设计已预留按权限检索，但需单独确认。

建议用成熟 AI SDK 接入模型，网站自己控制权限和发布。人工编辑始终可用，模型故障不会让你无法管理网站。具体选择见 Agent 模块，不需要你挑技术库。

## 怎样算完成

1. 手机和电脑都能从首页找到文章、项目、社媒；详情版式与当前原型一致，键盘也能操作。
2. 你能用示例文章完成“编辑 → 预览 → 发布 → 修改 → 恢复”，不用改源码；取消不产生写入。
3. 未解锁用户拿不到受限正文，搜索、引用、AI、附件和页面源代码遵守同样的权限。
4. AI 能回答有依据的问题、说明不知道的内容，来源可定位；配置无效、停止回答、断网均有清楚出口。
5. Agent 只能提出允许范围内的变更；确认后执行一次；旧版本冲突或登录过期时不会偷偷覆盖。
6. 火星主线、直接进入主站、重看归航、返回对话均走通；关闭动效仍能完成任务。
7. 开发交付可使用标注示例；以真实个人网站对外发布前，再替换并确认个人内容、费用和部署地址。
