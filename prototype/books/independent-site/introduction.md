# 写在开始之前

这是一份用于验证书籍栏目与协作流程的示例书稿，不是黄凌波已经正式出版的作品。书名、章节和内容都可以在确认真实选题后替换。

## 这本书想回答什么

一个个人网站，可以怎样同时承载表达、作品和一个小生意？这份示例从明确用途开始，讨论内容如何组织，以及怎样把交付说明说清楚。

阅读不需要先理解所有技术，也不需要购买任何东西。先找到自己最关心的问题，再决定是否继续深入。

## 怎样阅读

第一章关注网站服务谁、希望读者完成什么。第二章讨论公开内容、商品介绍与交付边界。可以顺序阅读，也可以通过左侧目录跳读。

左侧是全书章节，右侧是本章小节。它们解决不同的问题：换一章，与在同一章内找到某个话题。

## 怎样参与修改

标题旁的“查看源文件”打开本章对应的 Markdown 文件。“编辑此章”打开 GitHub 编辑入口；普通读者需要登录，按 GitHub 提示创建分支或 Fork，再提交 Pull Request。

提交建议不等于内容已经发布。维护者检查差异并合并后，还需要重新生成、检查和发布网站。请不要把密码、真实客户信息或付费正文放入公开修改。
